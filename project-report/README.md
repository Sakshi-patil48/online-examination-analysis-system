# SmartExams - Minor Project Report Documentation

This directory contains the complete, professional B.Tech CSE Minor Project Report generated for **Online Examination Analysis System (SmartExams)**.

---

## 📁 Generated Deliverables

1. **`Online_Examination_Analysis_System_Report.docx`**: Fully editable Microsoft Word report formatted according to B.Tech academic guidelines (A4 portrait, 1-inch margins, custom headers, 12 tables, 6 figures, code snippets, 35 Viva Q&As).
2. **`Online_Examination_Analysis_System_Report.pdf`**: Final formatted PDF project report ready for direct printing or digital submission.
3. **`architecture_diagrams/`**: High-resolution 300 DPI PNG diagrams:
   - `01_system_architecture.png`
   - `02_use_case_diagram.png`
   - `03_data_flow_diagram.png`
   - `04_er_diagram.png`
   - `05_ai_evaluation_flow.png`
   - `06_proctoring_workflow.png`

---

## ✏️ How to Edit Student / Guide Placeholders

Open `Online_Examination_Analysis_System_Report.docx` in Microsoft Word or Google Docs and replace the following brackets:

- **`[Student Name]`** ➔ Enter your name (e.g. Sakshi Patil)
- **`[PRN / Roll No]`** ➔ Enter your college roll number / PRN
- **`[Guide Name]`** ➔ Enter your project guide's name

---

## 🔄 How to Regenerate Reports

If you modify backend code or diagrams and want to regenerate the DOCX & PDF reports:

```bash
# Navigate to backend directory
cd backend

# Activate virtual environment
..\venv\Scripts\activate

# Run diagram generator & report compiler
python build_diagrams.py
python build_full_report.py
```
